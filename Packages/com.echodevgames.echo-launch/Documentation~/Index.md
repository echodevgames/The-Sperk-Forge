# First Light - Package Documentation

First Light is the startup coordination package for The Sperk's Forge - EchoDevGames Game Systems Suite.

This documentation is divided into user-facing guidance and developer-facing architecture records.

## Current Status

- Package version: `0.1.0`
- Development stage: Package skeleton
- Runtime startup behavior: Not implemented
- Installation mode currently tested: Embedded package
- Unity baseline: `6000.3.8f1`
- Minimum declared Unity version: `6000.0`

This version establishes only the Unity Package Manager identity, assembly boundaries, and documentation structure.

## Architectural Authority

The complete suite architecture and approved First Light package specification live in the repository's `Plan Documentation` Obsidian vault.

Package documentation summarizes and applies those authorities. It does not replace them.

## Current Limitation

First Light does not yet perform startup work.

There is currently no:

- Runtime launch root
- Startup sequence
- Startup step executor
- Launch report implementation
- Splash presenter
- Direct-scene initializer
- Setup tool
- Standalone Laboratory

Those features belong to later authorized checkpoints.
