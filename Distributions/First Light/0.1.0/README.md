# First Light 0.1.0 Distribution Kit

Start here when receiving First Light outside the development conversation.

## Files

- `com.echodevgames.echo-launch-0.1.0.tgz` - Unity Package Manager tarball.
- `FIRST_LIGHT_COMPLETE_USER_HANDOUT.md` - detailed installation, setup, capability, troubleshooting, limitations, and evidence reference.
- `DISTRIBUTION_MANIFEST.md` - artifact identity, scope, exclusions, and qualification state.
- `DISTRIBUTION_BUILD_RECORD.txt` - generated source baseline, artifact size, and artifact hash.
- `SHA256SUMS.txt` - SHA-256 integrity hashes.

## Recommended Order

1. Read `DISTRIBUTION_MANIFEST.md`.
2. Verify the tarball against `SHA256SUMS.txt`.
3. Read the installation and five-minute sections of `FIRST_LIGHT_COMPLETE_USER_HANDOUT.md`.
4. Install/evaluate the tarball.
5. Use the handout's reporting checklist for any issue.

## Current Qualification Boundary

This kit makes the First Light `0.1.0` artifact available for handoff/evaluation.

The external clean-project tarball route has **not yet completed release qualification**. Do not interpret the existence of this folder as a stable/public-registry support claim.
